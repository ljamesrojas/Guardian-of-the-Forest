#  Guardians of the Forest

Welcome to **Guardians of the Forest**, our very first web development project! This is a front-end website dedicated to advancing **UN Sustainable Development Goal 15: Life on Land**. Our mission is to raise awareness about deforestation, protect biodiversity, and inspire people to preserve nature.

## Project Overview
"Guardians of the Forest" is an interactive educational platform. It teaches users about the importance of terrestrial ecosystems and provides actionable steps to combat habitat loss. As our first development project, it focuses heavily on clean semantic structure, responsive design, and smooth user interactions.

### Key Features
*   **Educational Hub:** Deep dive into the core issues of SDG 15 (deforestation, desertification, and biodiversity loss).
*   **Interactive Footprint Calculator:** A simple JavaScript quiz to help users measure their environmental impact.
*   **Action Center:** A dedicated space showing users how to volunteer, donate, or make daily lifestyle changes.
*   **Fully Responsive:** Optimized for seamless viewing on desktops, tablets, and mobile devices.

## Tech Stack
*   **HTML5:** Semantic markup for structure and accessibility.
*   **CSS3:** Custom layouts, modern typography, flexbox/grid, and smooth transitions.
*   **JavaScript (ES6+):** Dynamic content rendering, mobile menu toggles, and interactive elements.
